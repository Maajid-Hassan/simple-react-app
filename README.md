# zenflow-todos-app

## Setup

Use Node.js version 20.

If you use nvm, install and use it with:

```bash
nvm install 20
nvm use 20
```

Then install dependencies:

```bash
npm install
```

Build the app:

```bash
npm run build
```

Start the development server:

```bash
npm run dev
```

## About the app

ZenFlow Todo App is a simple productivity dashboard for managing tasks with a clean, modern interface. It helps you organize work into categories such as today, upcoming, and completed items, while also offering filters and a visual task board experience.

The app is built with React and Vite, making it easy to run locally and extend with additional features over time.
